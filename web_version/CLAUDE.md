# Web Version
Inherit the common project guidance from ../CLAUDE.md.
Follow the final PDF example: purple gradient background, white card, black ink on a white canvas, CLEAR and PREDICT buttons, and three ranked prediction bars. Invert canvas pixels before posting to /predict. Keep pointer input usable with mouse, touch, and pen. Ignore stale results after clearing or editing the canvas. Use the shared Python recognition engine. Run with ../Start Web.bat or python server.py. All code and comments must be English and new source files must include creation date and time comments.
